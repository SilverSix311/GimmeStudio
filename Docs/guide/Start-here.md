# Start here: your first film

A complete path from an idea to a local preview.

In GimmeStudio: **Help → Start here: your first film**. Tool: `overview`.

## Before you begin

- Start GimmeStudio.cmd from the portable folder. The dashboard opens at http://127.0.0.1:8190.
- Use the Production selector to choose a project, or New project to create one. Tutorials work with any production.
- For your first test, make one character, one scene and one five-second shot. Expand after the first preview works.

## Make your first preview

1. Open Project brief → Edit project brief. Save a name, story goal, audience and visual style.
2. Open Character workshop → Create character. Describe appearance, clothing and personality; save the design.
3. Choose Generate design. Start ComfyUI using the header control; unload the AI Director model first if one is loaded.
4. Stage the image workflow, then open ComfyUI canvas. Click Load studio shot, inspect the graph, and click Run.
5. After generation finishes, choose Collect completed takes. Open Asset library and review the image.
6. Create a scene in Scenes, then add a shot with a clear action and camera direction. Select your reference image when generating its take.
7. For a quick animatic, add the still to Timeline & sound and set its duration. For motion, first generate a video take through Cinema Studio.
8. Save the timeline, then render it. Play the output and review composition, timing and sound.
9. If there is speech, transcribe the final rendered video in Dialogue & subtitles. Correct the captions and download SRT or VTT.
10. Export a local VISION package from Export & handoff. Cloud generation is a separate choice.

## What success looks like

You have a saved project, reviewed reference, shot, playable local preview and a portable export. A successful render proves the pipeline works; it does not automatically approve the art.
