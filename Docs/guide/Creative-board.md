# Creative board

Arrange references and notes into a visual story plan.

In GimmeStudio: **Help → Creative board**. Tool: `board`.

## Plan visually

1. Open Creative board and choose Add card. Select an existing element, scene, shot or asset, or create a text note.
2. Drag cards by their headers. Add annotations using Edit note.
3. Choose Connect cards to show a relationship between two cards.
4. Click Save board before leaving. Reopen it to continue the layout.

## What connections mean

Board connections describe creative relationships. They do not run inference or automatically schedule generation. Use a ComfyUI workflow for execution.
