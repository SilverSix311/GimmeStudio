# Assets, comparisons and review

Import media, compare versions and select the take you want.

In GimmeStudio: **Help → Assets, comparisons and review**. Tool: `assets`.

## Organize your media

1. Upload media from Asset library, or put larger files under Input and use workspace-relative import. Browser uploads are limited to 64 MB per file.
2. Choose Edit / review to name the asset, assign a folder label, add notes and set its review status.
3. Select two comparison checkboxes to compare variants. Examine identity, hands, text, framing and continuity.
4. Use in shot selects the current take for a shot. Approval and shot selection are separate decisions.
5. For training images, assign an element, write an image-specific caption, and choose train or validation split.

## Understand the records

Imported media is copied into the project asset directory using content hashes. Reviews, folders and notes are metadata; they do not alter the original pixels. Generated outputs start pending review. Keep rejected variants when their notes explain what to avoid.
