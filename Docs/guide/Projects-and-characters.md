# Projects, characters and scenes

Create worlds, edit designs, and keep references attached to the right production.

In GimmeStudio: **Help → Projects, characters and scenes**. Tool: `characters`.

## Build a reusable world

1. Choose New project and give the production a name. Edit its brief and style on Project brief.
2. In Character workshop choose Create character. Save name, pronouns, design description and continuity notes. LoRA trigger is optional.
3. Import reference images through Asset library, then Edit design to select those references. Multiple references can be selected with Ctrl/click.
4. Use Locations & objects for environments and props. These are saved world elements, just like characters.
5. In Scenes, create a setting with description, lighting, palette and cast. Add shots from that scene to retain the link.
6. Use Edit design whenever you want to change a character. Generate design creates a new exploration; it does not replace approved references by itself.

## Keep identity consistent

- State stable physical details separately from the action of a particular shot.
- Review new images before assigning them as references. Fixed seeds alone do not lock identity.
- The project selector changes the working production. Saved chats and elements stay with their project.
- Trash removes an item from active lists. Restore it in Jobs & history.
